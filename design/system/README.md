# Armory design tokens

`tokens.json` holds the Obsidian direction's design tokens in W3C Design Tokens format (`$value`, `$type`, `$description`). Every value was **extracted from the CSS in `design/directions/_build/a_obsidian.py`** (2026-10-01), so the tokens match the mockups exactly. Where the CSS has a custom property, the description names it (`--bg`, `--acc`, …).

## Groups

| Group | What it holds |
|---|---|
| `color.bg`, `color.surface.1-3`, `color.border` | Near-black neutrals. `surface.1` → `3` get lighter as they rise. `border.default` is the hairline. |
| `color.text.primary / muted / dim` | Three text tiers (`--ink`, `--mute`, `--dim`). |
| `color.accent.*` | Ember #FF6A2B, the only saturated colour. `text` is the lighter accent for text on dark. `onAccent` is the dark text used on filled Ember. `tint`, `glow` and `border.*` are alpha variants. `state.*` covers focus, selected and active. |
| `color.status.success / warn / error` | Green, amber and rose. **warn and `color.demoTag` are the same amber (#E8B04B)** that marks Demo data / Example / Pending. Never use it decoratively. |
| `color.rarity.*` | Muted cosmetic tier tints. They are not accents. |
| `font.family.headline / ui / mono` | Bricolage Grotesque (big headlines and the text wordmark only), Geist (UI and body), Geist Mono (labels, tags, addresses). |
| `font.headlineSettings` | Bricolage at 800, `font-stretch:82%`, `opsz` 96. |
| `typography.headline.*`, `.ui.*`, `.mono.*` | The size scale as it's used: size, line-height, weight and tracking per role. |
| `space.*` | Spacing values the mockups use (px keys). It's an observed set, not a strict 4px grid. |
| `radius.*` | 6px for tags up to 22px for feature cards. `card` = `--r` 14px. |
| `size.*` | Control heights, the container, the progress bar and its still tip, and the mascot placeholder footprints. |
| `shadow.*`, `blur.*` | Elevation (floating panels, Ember button glow, focus ring) and backdrop blurs. |
| `breakpoint` | `sm` 640, `md` 900, `lg` 1200, `xl` 1440 (min-width). Desktop mockups are drawn at `xl`. Since step 8, the CSS ships desktop-first `@media (max-width: next − .02px)` rules at 1199.98 / 899.98 / 639.98px; mobile renders are at 390px (`*-mobile.png`). |
| `color.danger.*`, `color.banner.*`, `color.soon` | Danger button, site-wide beta banner, Coming soon styling. |
| `size.icon.*` | Launch-type icon grid (24px) and stroke (1.75). |
| `zIndex` | `base` 1 (overlays inside cards) and `nav` 10. |
| `motion` | Duration 0. **No animation anywhere** (Barton, 10/1). |

## Rules
- Ember is used for primary actions, progress fill and the bar tip, and active and focus states. Nothing else is saturated.
- Text on filled Ember is `color.accent.onAccent` (#120805), never white (white fails contrast).
- The headline font is for big headlines and the wordmark. Body copy, numbers and UI use Geist and Geist Mono.
- Tokens follow the CSS. If the mockups change, re-extract the tokens rather than editing them by hand.

## Files in this folder
- `tokens.json`: design tokens (above).
- `a11y.md`: step 8 accessibility checks (contrast, focus, labels, aria, headings) and results.
- `components.html` + `components.png`: buttons, chips, cards, inputs, fact rows, progress bar, chart styling, type icons, beta banner, deposit-cap slot and the mascot slot (temporary knight placeholder art from `design/placeholder/`). Generated by `design/directions/_build/a_obsidian.py` (`components()`), so it uses the same CSS as the mockups.
- `icons/`: one line icon per launch type: `plain.svg`, `hybrid.svg`, `burn.svg`, `tax-split.svg`, `raffle.svg`. 24×24, 1.75 stroke, round caps, `currentColor`, abstract shapes (no mascot motifs). Plain, Hybrid and Burn are live; Tax split and Raffle render dim with a "Coming soon" chip. Also generated by `a_obsidian.py` (`TICONS`).

## Changelog

### 2026-10-01 (chain alignment)
- New CSS class `.chip.pd` ("Pending deploy"): dashed amber outline and hollow dot, using the existing `color.status.warn.chipText` (#e8c27a). No new token values.
- `.offc` (off-chain prep callout in the launch wizard) uses existing surface, border and text tokens.

### 2026-10-01 (itinerary step 8)
- **Changed** `color.text.muted` from `#8b909a` to `#a0a5ae` (8.0:1 on `--bg`).
- **Changed** `color.text.dim` from `#5d626c` (3.3:1, failed) to `#858a94` (4.7:1 or better on bg and every surface). `color.soon` is an alias of dim, so Coming soon chips now pass too (they were 3.1:1).
- **Added** `color.accent.state.focusOutline` (= `color.accent.text`, #ff9a62), plus `size.focusOutline.width` 2px and `size.focusOutline.offset` 2px for the static `:focus-visible` outline.
- Responsive CSS now ships, using the existing breakpoints; no new breakpoint values.
- Unchanged: `motion.duration` stays 0ms. Focus styles don't animate.

### 2026-10-01 (itinerary step 3)
- **Added** `color.accent.state.pressed` = `#E85A1E`. Also added to the CSS as `--accp`, used by `.btn.a:active`.
- **Defined** `breakpoint.sm` 640px, `breakpoint.md` 900px, `breakpoint.lg` 1200px, `breakpoint.xl` 1440px. These replace the empty placeholder.
- **Added** `color.danger.tint`, `color.danger.tintPressed`, `color.danger.border` and `color.danger.text` for the new danger button (`.btn.d`).
- **Added** `color.status.warn.chipText` and `color.status.warn.chipBorder` for the "Unaudited beta" chip (`.chip.ua`).
- **Added** `color.banner.bg`, `color.banner.border`, `color.banner.text` and `size.banner` (38px) for the site-wide beta banner (`.bbar`).
- **Added** `color.soon` (an alias of `color.text.dim`, used on a dashed `color.border.strong` outline) for Coming soon chips and cards.
- **Added** `size.icon.type` (24px) and `size.icon.typeStroke` (1.75) for the launch-type icons.
- New CSS classes with no new token values: `.btn.gh` (ghost: transparent, `text.muted`), `.btn.off` / `[disabled]` (45% opacity, global), `.tchip` (launch-type chip), `.chip.bt` (Beta) and `.capslot` (deposit cap slot).
- Unchanged: `motion.duration` stays 0ms. Nothing animates.
