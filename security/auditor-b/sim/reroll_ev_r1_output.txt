Part E: proper VRF but with the documented `expire` refund used as a free abort (R1-B-02, Switchboard only)
====================================================================================================
If a requester learns the Switchboard value off-chain before reveal and nobody else reveals before deadline_slot,
`expire` refunds principal + fee minus VRF cost. A bad draw then costs only the VRF cost; only good draws settle.

Selective expiry of an attacker's OWN earlier request also changes the pool the later request draws from
(k own pending requests ahead -> up to 2^k pool states to choose between). Same fix.

Part F: launch-window rare farming (reroll priced in tokens is cheapest when the token is cheapest)
====================================================================================================
EXAMPLE curve: constant product, virtual reserves 30.0 SOL / 1,073,000,000 tokens (unsourced example).
   tokens sold     0M: floor(R=1M) = 0.0280 SOL, attempt @200bps = 0.00366 SOL, E[cost] legendary =   3.659 SOL, 1/1 =    36.59 SOL
   tokens sold    50M: floor(R=1M) = 0.0308 SOL, attempt @200bps = 0.00372 SOL, E[cost] legendary =   3.715 SOL, 1/1 =    37.15 SOL
   tokens sold   200M: floor(R=1M) = 0.0422 SOL, attempt @200bps = 0.00394 SOL, E[cost] legendary =   3.945 SOL, 1/1 =    39.45 SOL
   tokens sold   600M: floor(R=1M) = 0.1439 SOL, attempt @200bps = 0.00598 SOL, E[cost] legendary =   5.978 SOL, 1/1 =    59.78 SOL

If the collection later trades at floor 1.0 SOL (EXAMPLE) and a legendary at 20x floor:
   legendary farmed at launch costs ~3.66 SOL expected vs later premium 20 SOL -> EV ~16.34 SOL
   same farm after F reaches 1.0: E[cost] 23.10 SOL -> EV -3.10 SOL
   => the doc's scale-invariant fee is invariant to the CURRENT floor, not to the FUTURE premium. Early grinding
      is dominated by the flat SOL fee, and the snipers who already hold cheap tokens can do it first.
