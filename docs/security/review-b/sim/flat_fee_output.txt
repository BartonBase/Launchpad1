Max loss per floor NFT from the release fee = min(V, s_rel) <= 0.01 SOL (the holder can always choose not to
release, or sell the NFT on Tensor/ME; an arbitrageur bids at most V - s_rel - TX, so the fee is priced into
the NFT's exit value either way).

Fee-wallet income if every NFT is released in a panic vs the tokens those NFTs back (R=100k, C=10k):
   FDV  400: holders' tokens N x V =   400.0 SOL; release fees N x 0.01 = 100.0 SOL ( 25.0% of the value exiting)
   FDV  100: holders' tokens N x V =   100.0 SOL; release fees N x 0.01 = 100.0 SOL (100.0% of the value exiting)
   FDV   50: holders' tokens N x V =    50.0 SOL; release fees N x 0.01 = 100.0 SOL (200.0% of the value exiting)
   FDV   20: holders' tokens N x V =    20.0 SOL; release fees N x 0.01 = 100.0 SOL (500.0% of the value exiting)

Insider band arbitrage: the NFT bid floor sits at V - s_rel - TX for outsiders. The fee wallet (or a wallet
it funds) releases at net cost TX (the fee returns to itself): it can buy every NFT listed between V - s_rel and V
and redeem it, earning up to s_rel per NFT that nobody else can. Same on the capture side (sell NFTs up to V + s).
